# Security Policy

## Reporting a vulnerability

Please do not open a public issue.

- **In this app** (the launcher, options, image setup): report it privately through
  [Private Vulnerability Reporting](https://github.com/ulsklyc/yuvomi-home-assistant/security/advisories/new)
  of this repository.
- **In Yuvomi itself**: follow the [Yuvomi security policy](https://github.com/ulsklyc/yuvomi/security/policy).
